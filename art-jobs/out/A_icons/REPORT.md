## How to use

- **Every SVG** has a root `<g id="<name>">`; buttons split into `<g id="base">` (ring + disc) and `<g id="icon">`, so code can swap or animate the icon alone.
- **Buttons:** cream ring = safe actions, coral ring = Impostor/danger (`eliminate`, `vent`, `sabotage`). Ring, disc, screws, bevel and outline are identical for all eight. Use the `_disabled` PNG while an action is unavailable (it's a desaturated plum-grey copy of the same art, not a CSS filter).
- **Cooldown ring** (`cooldown_ring.svg`): `#track` is a 72% plum ring that dims the button's cream/coral ring; `#arc_stroke` is a circle, r = 100, centered 128,128, rotated -90 so it starts at 12 o'clock and fills clockwise.
  - `C = 2 * PI * 100 = 628.32`; `stroke-dasharray = "628.32 628.32"`; `stroke-dashoffset = C * (1 - progress)` where `progress` goes 0 to 1 (remaining or elapsed, your choice). In the SVG it's preset to 35%.
  - Phaser alternative (simpler): draw the `@192` track PNG, then each frame `g.clear(); g.lineStyle(16*s, 0xF5A54A); g.beginPath(); g.arc(cx, cy, 100*s, -PI/2, -PI/2 + 2*PI*progress); g.strokePath();` with `s = displaySize / 256`. Put the seconds number (Bungee) over the disc in code.
- **`icon_helmet_front`:** the suit, collar, chest and antenna ball use `fill: var(--suit, #CDCCD4)`; its shading is a translucent plum overlay, so any suit color shades correctly. In Phaser, use the `@64`/`@32` PNG with `setTint()`, or inline the SVG and set `--suit` to one of the 10 player colors. The PNGs bake in the default grey.

## Quality (honest)

- **Overall: 8/10.** The set reads as one family and matches the room/prop refs: plum outlines, flat two-tone cel shading, chunky bevels, cream/amber/coral stripe motif on the megaphone, emergency base and chest tab. Every button and badge stays readable at its real size on the dark HUD (see the strip at the bottom of `PREVIEW.png`).
- Strongest: `btn_report`, `btn_vent`, `btn_emergency`, `btn_map`, `btn_chat`, crown, stamp, gear, mic pair, task done, warning, helmet chip.
- Weaker:
  - `btn_eliminate` is the busiest icon (pin + balloon + burst); it still reads at 96 px, but the balloon string is fiddly.
  - `badge_skip`'s arrow and bar read more as "jump over" than "skip" (fine if it sits under a SKIP label).
  - Fixed after review: `badge_leave` now has a cream door frame so it reads on the dark HUD, and `badge_disconnected`'s cable is clipped inside its disc.
